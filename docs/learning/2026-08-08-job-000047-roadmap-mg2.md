### Regras de comunicação (evitar atrasos)

1. **Gate antes de próxima onda** — Patrocinador responde «passou / falhou / adiar» em ≤ 48 h após pedido do CEO.  
2. **Job concreto** — cada despacho tem título acionável + critério de done (ex.: «smoke W 1ª→5ª em `/mg2`»).  
3. **Lacuna declarada** — se faltar dado, CEO/Engenheiro declaram ignorância; não inventam escopo.  
4. **SCENE_REV** — toda entrega oficina incrementa revisão de cena + build `npm run build` OK.  
5. **Briefing vivo** — após cada gate relevante, actualizar `docs/mvp/briefing-operacional-mg2.md`.
