## 8. Comunicação anti-atraso

| Regra | Detalhe | Owner |
|-------|---------|-------|
| **SLA gate** | Patrocinador responde passou/falhou/adiar em ≤ 48 h após pedido CEO | Patrocinador |
| **Job concreto** | Título acionável + critério de done (ex.: «smoke W 1ª→5ª em `/mg2`») | CEO |
| **Lacuna declarada** | Sem dado → ignorância explícita; não inventar escopo | CEO / Engenheiro |
| **SCENE_REV** | Toda entrega oficina incrementa revisão + `npm run build` OK | Engenheiro |
| **Briefing vivo** | Actualizar `docs/mvp/briefing-operacional-mg2.md` após gate relevante | CEO / curadoria |
| **Escalada atraso** | Gate > 72 h → CEO regista learning + lembrete único (sem spam) | CEO |
