## 1. Ponto exacto de isolamento

| Passo | Onde |
|-------|------|
| 1 | `montarEntradaMre` continua a anexar fio (D3 / sem RFR). |
| 2 | `enriquecerEntradaMreComLfc` resolve consumo LFC (IMP-092.4). |
| 3 | **`aplicarIsolamentoRfrNaEntrada`** — se restrição explícita **e** `lfcConsumo.autorizado` (sem ambiguidade): remove `[Fio recente…]` e reparse `[Facto do utilizador…]` / `[LASTRO DO TURNO…]` da `mensagem`; esvazia `entrada.historico` **só** no envelope MRE; anexa marcador RFR. |

```text
montarEntradaMre  →  (fio HFC presente)
enriquecerEntradaMreComLfc
  → obterConsumoLfcParaMre / aplicarConsumoLfcNaEntrada
  → aplicarIsolamentoRfrNaEntrada
       ├─ sem RFR → no-op (fio permanece)
       ├─ RFR + LFC não autorizado / ambíguo → no-op (CM-RFR-1 / G5)
       └─ RFR + LFC autorizado → isola fio/reparse da mensagem + historico envelope
```

## 3. Detector (contrato ADR-023 — sem heurística extra)

Alinhado a **RFR-G2/G3** e exemplos ilustrativos:

1. «analisando apenas/somente os fatos/factos registados/registrados…»
2. «só/apenas/somente com os factos/fatos do lastro…»
3. «com base unicamente nos factos/fatos assertados…»

Equivalente semântico **inequívoco**: (`analis*` | `com base`) + restrição (`apenas`/`somente`/`só`/`unicamente`) + `fato(s)`/`facto(s)` + (`registados`/`registrados`/`assertados`/`lastro`).

**Não** detectar só por «factos» ou nome de caso.
