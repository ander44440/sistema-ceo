## 2. Fluxo integrado

```text
instrucao → detectarModoRespostaRestrita
  ├─ registo / confirmacao / factos / dado_unico
  │     ├─ sem COA → recusa R/W persistente (sem prosa «guardado»)
  │     ├─ registo → LfcWriter.criarCaso → prosa «guardado» só se autorizaProsaGuardado
  │     ├─ confirmacao → LfcWriter.corrigirFacto (correçãoExplícita)
  │     ├─ factos / dado_unico → LfcReader (canónico)
  │     │     └─ sem caso LFC → fallback reparse temporário (nunca se LFC tem activos)
  │     └─ caso_ambiguo → pedir casoId
  └─ sim_nao / lacunas → caminho legado (semântica não factual intacta)
HFC continua a registar o fio (ortogonal).
```
